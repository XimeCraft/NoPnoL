### 1.3 Responsibilities

The primary responsibilities of this app:

* Contains 20+ projects
* Allow access to each project documents and visualization dashboard
* Allow to implement CI/CD with Microsoft Azure Function
* Allows access to PowerBI published dashboard

Other Desired features:

* Message system of each project
* Alarm system of outliers

* Send notificaiton of alamrs to users  



## 2 Functional Objectives

### 2.1 High Priority

1. Should be online.
2. Should display a project contains page: document, result analysis, dashboard, code, history release, comments.
3. Should display the details of a project: document, result analysis, code.
4. Should implement functional pages: Wiki, Contact, navigation and search bar.
5. A logo icon could return to top page
6. Should add projects on website

### 2.2 Medium Priority

1. Should display dashboard page
2. Top page should support a search bar will allow a text searching of projects:
   * Find all words specified
   * Find any word specified
3. A Q&A part under each project
4. Account system

### 2.3 Low Priority

1. Allows a history release page under each project.
2. History release page should check the changes of each edition
3. Support CI/CD



## 3. Non-Functional Objectives

### 3.1 Usability

* Users who already knows what project they are interested in should be able to locate and view the page in \** seconds
* The number of pages navigated to access project information from the top page should not exceed 2

### 3.2 Security

* Users who prefer to view the code or leave the comments should have their accounts.

### 3.3 Supportability

* This app should be viiewable from Chrome, Safari, Microsoft Edge

### 3.4 Online Documentation and Help

* This app should provide a documentation page of how to navigate the site.
* This app should provide a help page that explains edition, upgrade and debugging
